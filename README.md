# Launchpad

**Get started with evidence-driven software validation.**

Launchpad is the documentation and runnable-example home for [Forge](https://github.com/zerogravit1/forge), [Tun](https://github.com/zerogravit1/tun), [Atticus](https://github.com/zerogravit1/atticus-mock-service), and [Shipweard](https://github.com/zerogravit1/shipweard).

It helps developers install, configure, understand, and adopt those tools through reproducible examples and integration guides. **Launchpad is not another application or runtime.**

Read the [Launchpad North Star](docs/NORTH_STAR.md) for its mission, scope, and standards for examples.

> **Status:** The example catalog and quickstarts are planned. The first target is TypeScript/Vitest once Forge has a meaningful test-selection workflow.

The broader portfolio vision is documented in the [Evidence-Driven Software Validation North Star](https://github.com/zerogravit1/launchpad/wiki/North-Star-%E2%80%90-Evidence-Driven-Software-Validation).
